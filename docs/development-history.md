# Development History

Model Landscape's warehouse monitoring app was originally developed as Model
Lens before it was renamed and combined with the `mlflow-lens` SDK and product
documentation in this repository.

The original Model Lens development history is intentionally preserved in this
repository through an ancestry-only merge. That history includes the control
plane, refresh workflow, Databricks App UI, Lakebase support, drift and
performance analytics, deployment hardening, and customer-feedback fixes that
formed the foundation of the current `model_landscape` app package.

The ancestry merge does not replace the current Model Landscape source tree.
It exists to keep the original implementation commits reachable for audit,
attribution, and future archaeology while the current repo continues from the
renamed and extended Model Landscape codebase.
