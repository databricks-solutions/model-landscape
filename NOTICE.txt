Notes on specific licenses:

- LGPL-3.0-or-later (psycopg, psycopg-binary): Used as a dynamically linked
  Python library via the standard `import` mechanism. Recipients may replace
  the psycopg installation with another LGPL-compatible version.
- MPL-2.0 (certifi): Distributes the Mozilla CA certificate bundle. File-level
  copyleft applies only to modified MPL-licensed files, not to combined works.
- Dual-licensed packages (cryptography, packaging, python-dateutil): Use is
  governed by either license at the user's choice.

How to regenerate this list:

    uv lock                                            # resolve dependencies
    uv export --no-hashes --no-emit-project --no-dev   # snapshot
    # then refresh this table from PyPI metadata for each resolved package.
